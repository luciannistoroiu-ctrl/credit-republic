You said: ce poate face Cloudinary

Claude responded: Cloudinary este o platformă cloud pentru gestionarea și optimizarea de imagini și video. Iată ce poate face, pe scurt:

**Funcții principale**

**Stocare și livrare**
- Upload de imagini/video în cloud, cu acces prin URL
- CDN global pentru livrare rapidă

**Transformări on-the-fly (direct din URL, fără procesare manuală)**
- Resize, crop, decupare inteligentă pe subiect (face/object detection)
- Compresie și optimizare automată (format + calitate în funcție de browser/device)
- Efecte: filtre, overlay-uri, text pe imagine, watermark-uri
- Conversii de format (JPEG, PNG, WebP, AVIF etc.)

**Video**
- Transcodare, trimming, thumbnail-uri automate din video
- Streaming adaptiv

**AI/automatizare**
- Eliminare fundal automată
- Generative fill/expand (completare imagine cu AI)
- Recunoaștere conținut, tagging automat, moderare
- Crop inteligent bazat pe subiectul principal

**Integrare**
- SDK-uri pentru majoritatea limbajelor/framework-urilor (React, Node, Python etc.)
- Widget-uri de upload gata făcute
- API și webhooks pentru automatizări
